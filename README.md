# דף נחיתה – המכינה החרדית האוניברסיטאית

דף נחיתה לאיסוף לידים (שם פרטי, שם משפחה, טלפון, אימייל). אחרי מילוי הטופס נפתח המידע המלא על המכינה וחוברת להורדה.

- `index.html` – הדף עצמו
- `apps-script.gs` – קוד Google Apps Script שקולט את הלידים לגיליון Google Sheets
- תגי UTM מהקישור (`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`) נשמרים עם כל ליד
